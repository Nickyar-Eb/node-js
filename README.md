# سرور نمونه Express.js (پروژه Hello World)

این پروژه یک وب‌سرور ساده است که با استفاده از **Node.js** و فریم‌ورک **Express.js** پیاده‌سازی شده است. این پیاده‌سازی منطبق بر **تمرین ۱ (فصل اول)** کتاب زیر انجام گرفته است:

> **The Complete Developer: Master the Full Stack with TypeScript, React, Next.js, MongoDB, and Docker**  
> نویسنده: Martin Krause (انتشارات No Starch Press، سال ۲۰۲۴)

---

## 📌 مشخصات پروژه

* **محیط اجرا (Runtime):** Node.js
* **فریم‌ورک وب:** Express.js (`نسخه 4.x`)
* **پورت اجرایی:** `3000`
* **مسیرهای سرور (Endpoints):**
  * `GET /hello`: ارسال پیام متنی ساده `"Hello World!"` به کلاینت

---

## 🚀 پیش‌نیازها و راه‌اندازی

### پیش‌نیازها
برای اجرای این پروژه باید [Node.js](https://nodejs.org/) روی سیستم شما نصب باشد.

### ۱. نصب وابستگی‌ها
پس از دریافت یا کلون کردن پروژه، دستور زیر را در ترمینال پوشه پروژه اجرا کنید تا پکیج‌های لازم نصب شوند:

```bash
npm install
```

### ۲. اجرای سرور
برای روشن کردن و اجرای سرور دستور زیر را بزنید:

```bash
node index.js
```

پس از اجرای موفق، پیام زیر در ترمینال نمایش داده می‌شود:

```text
Listening on 3000
```

## 🧪 تست و مشاهده خروجی

مرورگر اینترنت خود را باز کرده و به آدرس زیر مراجعه کنید:

```text
http://localhost:3000/hello
```

**خروجی مورد انتظار:**
